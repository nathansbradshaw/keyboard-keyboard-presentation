固定する Make it work. Then anchor the wire so it stays working.
Those orange wires are the real fix on our keyboard. The board came back with the wrong connections, so we patched it instead of throwing it away. Start with the power off. Use the schematic and continuity mode to find the two points that should be connected. If copper is joining something it should not, make one shallow cut with a sharp knife, inspect it under magnification, and check that the path is actually open. Solder the jumper to a pad or via if you can. If you have to scrape solder mask, expose only a little copper, add flux, and tin it quickly so the trace does not lift. Use short insulated wire and anchor it after the electrical fix works; Kapton is fine for a test, while UV solder mask or electronics-safe adhesive can hold the final repair. Check continuity and nearby shorts before power, then use a current-limited supply for the first test. Never use continuity or resistance mode on a powered board. Transition: sometimes the copper is right and the component is what has to leave.
