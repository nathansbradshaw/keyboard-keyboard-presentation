The state machine stays put.

constants.rs keeps two different facts apart. SWITCH_MAP says where each switch is physically wired: a mux and channel. SWITCH_TO_NOTE says which pitch that switch should play in the Wicki-Hayden layout. process_events then applies octave and channel settings. A PCB revision changes the first table; a new musical layout changes the second; another MIDI transport changes neither. These are abbreviated but ordered excerpts from the real arrays. Transition: zoom back out and turn these files into an implementation order that always leaves a runnable instrument.
