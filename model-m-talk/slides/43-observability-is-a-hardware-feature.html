Debug one boundary at a time.

End the firmware section in the same editor, now with the terminal open. The real code can log raw, filtered, baseline, and delta values through RTT, then log the semantic NoteOn it sends. The numbers shown in the console are illustrative, while the log formats are copied from main.rs. Three LEDs show heartbeat, MIDI transmit, and MIDI receive; the OLED shows settings and the last event; a MIDI monitor verifies bytes before the synthesizer. If raw does not move, stay with hardware. If an event appears but no bytes leave, inspect the queue and UART. If bytes are correct but there is no sound, the failure is downstream.
