pub fn note_on(
    &mut self,
    note: u8,
    velocity: u8,
) {
    let status = 0x90 | self.channel;

    self.send_byte(status);
    self.send_byte(note & 0x7F);
    self.send_byte(velocity & 0x7F);
}

Never block the hot path.

The split editor makes the boundary visible. timer_handler puts semantic events into the fixed 64-entry queue and returns. process_events runs at priority 2 and calls MidiSender, whose UART write may block. A three-byte NoteOn occupies 30 framed UART bits; at 31,250 baud that is about 0.96 milliseconds—almost the entire scan period before a chord is considered. The current enqueue path discards a full-queue error, so a production revision should count and expose overflows. Transition: the event's switch index still has to become a musical note.
