These are the message families implemented by MidiSender. Note On and Note Off carry note and velocity. Control Change carries a controller number and its value; the firmware uses CC for twelve pots, vibrato on CC 1, volume when a mapped pot uses CC 7, and All Notes Off on CC 123. Program Change is the exception here: it has only one data byte, so two bytes total. Three special keys select programs zero, one, and two for triangle, square, and saw in the paired synth. Pitch bend packs a fourteen-bit value into two seven-bit data bytes, with 0x2000, decimal 8192, as center. By default melody uses channel 1 and drum pads use channel 10; code stores those as zero and nine. Both are editable in the settings screen. The important protocol idea is that the upper nibble of the status byte selects the message family, while the lower nibble selects the channel.
