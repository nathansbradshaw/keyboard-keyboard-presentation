pub fn feed(&mut self, raw: u16) -> u16 {
    self.sum -= self.ring[self.index] as u32;
    self.sum += raw as u32;

    self.ring[self.index] = raw;
    self.index = (self.index + 1) % FILTER_SIZE;

    (self.sum >> FILTER_SHIFT) as u16
}

switch.rs contains the complete rolling-average update. Each key owns four samples and a running sum, so replacing the oldest reading is constant time. Dividing by four becomes a right shift. At a one-kilohertz scan rate the average sample age is about 1.5 milliseconds. A longer window would remove more noise but blur the two crossings used to calculate velocity. The output is compared with that key's baseline to produce an absolute delta. Transition: the state machine gives that delta musical meaning.
