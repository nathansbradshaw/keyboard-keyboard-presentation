境界線 · SYSTEM BOUNDARY The keyboard owns performance. The phone owns sound.
Start with the complete physical system. The modified Model M has 100 Hall effect key sensors. Its firmware turns continuous position into performance events and transmits standard DIN-5 MIDI at 31.25 kbaud. The external Synth Phone receives that data and owns tone generation plus live voice effects. The boundary sentence is the point: keyboard equals performance controller; phone equals sound engine.
