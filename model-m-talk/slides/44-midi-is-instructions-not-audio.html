演奏を送る。音は送らない。 Send the performance. Let the receiver make the sound.
MIDI is a control protocol. It does not put audio on the cable. Our keyboard is the controller: it decides that a key became note 60 with velocity 100. The receiving synthesizer chooses the oscillator, sample, envelope, effects, speakers, and therefore the actual sound. Read the example in hexadecimal. 0x90 is Note On on MIDI channel 1; the firmware stores that channel as zero because the low nibble ranges from zero through fifteen. 0x3C is decimal 60, middle C. 0x64 is decimal 100, the strike velocity. Channel voice data bytes are seven-bit values, so notes, ordinary velocities, controller numbers, and controller values recur in the range zero through 127. A separate Note Off ends the note. Transition: Note On is only one word in the performance vocabulary that this keyboard sends.
