NoteOn costs 30 bits on the wire

pub fn note_on(&mut self, note: u8, velocity: u8) {
    let status = 0x90 | self.channel;
    self.send_byte(status);
    self.send_byte(note & 0x7F);
    self.send_byte(velocity & 0x7F);
}

fn send_byte(&mut self, byte: u8) {
    nb::block!(self.tx.write(byte)).ok();
}

This is the real note_on method and blocking send_byte wrapper. DIN MIDI uses USART1 at 31,250 baud. Each UART byte carries one start bit, eight data bits and one stop bit, so a three-byte NoteOn occupies thirty wire bits: about 0.96 milliseconds. That is an inferred serialization time, not a measured end-to-end latency. The priority-15 scan task only enqueues the event; priority 2 drains the queue and performs the blocking writes.
