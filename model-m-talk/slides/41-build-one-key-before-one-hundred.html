This is the smallest complete path visible in the final code: read one raw value, filter it, turn it into one event, then send one note from the lower- priority task. Build toward that path in four runnable checkpoints. First hard-code middle C to prove transport. Then log one sensor. Then produce exactly one NoteOn and NoteOff. Only then scale the mux scan and tables to every key. A digital matrix changes the read and debounce steps, but the event and transport boundary can stay the same.
