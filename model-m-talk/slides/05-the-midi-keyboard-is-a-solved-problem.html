The obvious objection

“The MIDI keyboard is a solved problem.”

88 keys. Velocity. Done.

So why did we build the wrong one?

Because “solved” often means the assumptions have become invisible.

The piano icon is shorthand, not the project keyboard. Pause before “wrong one,” then reveal the unimpressed cat as the audience's practical objection: “Could've just bought a MIDI keyboard.” Transition: every input device carries assumptions.
