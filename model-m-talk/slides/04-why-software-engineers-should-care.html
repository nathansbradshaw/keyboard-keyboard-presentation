The thesis

Why software engineers should care

Interfaces are APIs

Except the caller has hands, habits, and muscle memory.

Analog becomes data

Noise, calibration, thresholds, events, state.

Latency is full stack

From magnet travel to the speaker cone.

Hardware sets constraints

Mechanical decisions become firmware decisions.

Protocols create freedom

A clean boundary let two weird devices cooperate.

Prototypes are architecture

Documents you can touch—and occasionally short.

This is the promise for the talk. Ask the audience to translate every physical detail into a software concept. Transition: start with the basic product question.
