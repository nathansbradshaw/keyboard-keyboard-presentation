SwitchPhase::FirstActuated { tick: t1 } => {
    if delta >= SECOND_DELTA {
        let elapsed = tick.saturating_sub(t1);
        let velocity = if elapsed == 0 {
            127u8
        } else if elapsed >= VELOCITY_WINDOW_MS {
            1u8
        } else {
            let v = 127u32.saturating_sub(
                (elapsed * 126) / VELOCITY_WINDOW_MS
            );
            (v + 1).min(127) as u8
        };

        self.phase = SwitchPhase::FullyActuated { velocity };
        Some(SwitchEvent::NoteOn { velocity })
    } else {
        None
    }
}

Fast crossing = high velocity.

The state machine makes the velocity calculation concrete. Crossing the first threshold records a timestamp. Crossing the second threshold measures elapsed milliseconds and maps a shorter time to a higher MIDI velocity. FullyActuated emits NoteOn only once. A separate lower release threshold returns to Idle and emits NoteOff, giving the key hysteresis. The real code also requires three consecutive confirmations at each transition; that debounce detail is summarized in the status bar. Transition: the new event still cannot be written to MIDI inside this one-millisecond task.
