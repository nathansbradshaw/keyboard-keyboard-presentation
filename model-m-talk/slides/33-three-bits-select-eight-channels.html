One address reaches all 13 muxes.

Open the helper that the scan just called. The channel number is treated as three binary bits. Bit zero drives s0, bit one drives s1, and bit two drives s2. The same three physical wires reach all thirteen multiplexers, so one address selects the same column everywhere. The ADC pins can then read many sensor groups in parallel. This is the direct bridge from the Rust loop to voltages on the PCB. Transition: because this work happens every millisecond, its priority must be protected.
