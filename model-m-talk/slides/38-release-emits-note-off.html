SwitchPhase::FullyActuated { .. } => {
    if delta < RELEASE_DELTA {
        self.debounce_count =
            self.debounce_count.saturating_add(1);

        if self.debounce_count >= DEBOUNCE_TICKS {
            self.phase = SwitchPhase::Idle;
            self.debounce_count = 0;
            Some(SwitchEvent::NoteOff)
        } else {
            None
        }
    } else {
        self.debounce_count = 0;
        None
    }
}
RELEASE_DELTA = 100DEBOUNCE_TICKS = 3

250full press threshold
100release threshold
3 quiet scans → NoteOff

No chatter near one boundary.

The previous slide showed NoteOn; this is its equally important other half. A fully actuated key does not release near the 250-count press threshold. It must fall below the separate 100-count release threshold for three scans. Only then does the state return to Idle and emit exactly one NoteOff. The gap between thresholds is hysteresis, which prevents a noisy signal from rapidly retriggering at one boundary. Transition: both semantic events now cross the queue because neither belongs on the MIDI wire inside the scan task.
