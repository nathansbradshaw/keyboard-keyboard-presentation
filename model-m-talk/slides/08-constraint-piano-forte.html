0. The hall effect switches create a variable change in the voltage, which is measured by the ADC, this gives us a continuous stream of voltage readings. We can choose two points on that stream and those points can be used to define the first key press and the second key press. we can measure the time between to calculate the velocity. 1. So a soft key press is defined by a long time between the first and second actuation points 2. A loud key press is defined by a short time between the first and second actuation points.
