Code and board must agree.

Start in a familiar place: the real repository. Cargo.toml selects RTIC, the STM32H750V HAL target, our libdaisy fork, a fixed-capacity queue, and the OLED driver. The neighboring .cargo/config.toml builds for the Cortex-M7 target and tells probe-rs the exact chip; Embed.toml enables RTT and GDB. The terminal command builds, flashes, and attaches to that specific board. The snippet removes unrelated dependencies, but every shown line is from the repository.
