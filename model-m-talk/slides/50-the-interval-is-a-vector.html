To understand Wicki–Hayden, build the hexagonal grid from the bottom up. Start with a whole-tone scale: C, D, E, F-sharp, G-sharp, A-sharp, then C again. Every horizontal move is two semitones. Add the complementary whole-tone scale in the row above; between the two rows, all twelve pitch classes are now present. But do not leave the rows directly aligned. Shift the upper row half a key so the intervals musicians reach for sit beside one another. From C, diagonally up-left lands on F, a perfect fourth; diagonally up-right lands on G, a perfect fifth. Repeat the first row two levels up and a vertical jump lands on C again, one octave higher. That compact fourth–fifth–octave neighborhood is the reason for the stagger. Transition: once that geometry is repeated, the same musical relationship keeps the same physical shape wherever it starts.
