for ch in 0..MUX_CHANNELS {
    set_mux_channel(ch, s0, s1, s2);
    cortex_m::asm::delay(480 * 10);

    let readings = read_all_adcs(adc, adc_pins);
    for (mux, &val) in readings.iter().enumerate() {
        mux_raw[mux][ch] = val;
    }

    for decoder_idx in 0..4u8 {
        set_decoder(decoder_idx, enb_a, enb_b, enb_c);
        cortex_m::asm::delay(480 * 5);
        let mux_idx = 9 + decoder_idx as usize;
        mux_raw[mux_idx][ch] = if decoder_idx < 2 {
            adc.read(adc_pin_a9).unwrap_or(0u32) as u16
        } else {
            adc.read(adc_pin_a10).unwrap_or(0u32) as u16
        };
    }
}

The wiring becomes a loop.

This is the actual shape of the ADC scan in timer_handler, with long pin arguments shortened. Each of eight mux addresses is broadcast to every mux. Nine ADC inputs are read directly; four more muxes are selected through the decoder and read from shared ADC inputs. Thirteen by eight gives 104 slots, and the mapping table identifies the 100 populated sensors. The settling delays are hardware-specific and must be measured, not copied blindly. Transition: this loop only stays regular if slower jobs run below it.
