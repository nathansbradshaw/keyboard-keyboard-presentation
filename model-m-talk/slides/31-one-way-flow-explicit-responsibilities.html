This is the implemented path across main.rs, hardware.rs, switch.rs, and midi.rs. A one-kilohertz TIM2 task scans the analog topology, each key's rolling filter reduces noise, and a state machine turns position into one semantic event. The high-priority path stops after placing that event into a fixed-capacity queue. A lower-priority task performs MIDI routing and the blocking UART writes. This decomposition is reusable: a digital matrix can replace the analog scan and filter while keeping the event queue and MIDI transport.
