CALIBRATION RULE Nothing may be pressed when “rest” is learned.
The firmware calibrates every physical switch separately because magnet height, sensor offset, assembly tolerance, temperature, and analog routing vary across the board. At boot, it averages 64 samples for each populated slot and primes every four-sample filter with that value. During normal use, a baseline can move only while the state machine is idle and the filtered signal is inside the release band. The IIR moves by one part in 1024 per scan and is clamped within 40 ADC counts of the last calibration anchor. The manual recalibration key snapshots a new anchor. The code uses an absolute delta, so either magnet polarity can work. The practical rule for your own build is simple: calibration is a measurement procedure, not a magic fix; the mechanism must be completely at rest.
