Fixed distance + measured time = strike velocity.

This excerpt is compressed from the real match arms while preserving the implemented behavior. A key begins Idle. Crossing an absolute ADC delta of 150 for three consecutive scans records t1 and emits nothing. Crossing 250 for three scans computes elapsed milliseconds. The 80-millisecond window is mapped inversely into MIDI velocity 1 through 127, so a fast crossing becomes a louder strike. FullyActuated emits NoteOn only once. Falling below the separate release threshold of 100 for three scans returns to Idle and emits NoteOff. The separated press and release thresholds provide hysteresis. For a digital switch, use the same state/event boundary with debounce and a fixed velocity; for an analog switch, tune both distances from recorded data. Transition: even a perfect event can still violate the scan deadline if it is sent synchronously.
