USART1 becomes a MIDI port

1 · CONFIGURE THE PERIPHERAL 
let tx = daisy13.into_alternate::<7>();
let rx = daisy14.into_alternate::<7>();

let serial = USART1.serial(
    (tx, rx),
    SerialConfig {
        baudrate: 31_250_u32.bps(),
        ..Default::default()
    },
    clocks,
)?;

let (tx, midi_rx) = serial.split();
let midi_sender = MidiSender::new(tx, 0);
2 · ENCODE A MESSAGE 
pub fn note_on(
    &mut self,
    note: u8,
    velocity: u8,
) {
    let status = 0x90 | self.channel;
    self.send_byte(status);
    self.send_byte(note & 0x7F);
    self.send_byte(velocity & 0x7F);
}

fn send_byte(&mut self, byte: u8) {
    nb::block!(self.tx.write(byte)).ok();
}

UART が運ぶ。MIDI が意味を与える。 UART moves bytes. MidiSender gives them meaning.
There is no special MIDI peripheral inside the STM32. At boot, main.rs puts Daisy pins D13 and D14 into alternate function 7, configures USART1 for 31,250 baud with the HAL defaults, splits it into transmit and receive halves, and gives TX to MidiSender. The sender begins on zero-indexed channel zero, displayed to musicians as channel 1. MidiSender is intentionally thin. It combines the message family with the four-bit channel, masks each data byte to seven bits, and writes the bytes through the UART. The snippets are condensed from the repository: some ownership and clock arguments are shortened for readability. Physically, TX reaches the DIN-5 output circuit; RX enters through the 6N138 optocoupler. The current receive path does not decode messages: timer_handler drains available RX bytes and flashes the MIDI RX LED.
