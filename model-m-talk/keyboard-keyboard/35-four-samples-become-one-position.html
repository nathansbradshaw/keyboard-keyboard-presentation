pub fn feed(&mut self, raw: u16) -> u16 {
    self.sum -= self.ring[self.index] as u32;
    self.sum += raw as u32;
    self.ring[self.index] = raw;
    self.index = (self.index + 1) % FILTER_SIZE;
    (self.sum >> FILTER_SHIFT) as u16
}

≈ 1.5 ms average age

This is the actual ChannelFilter feed method and delta calculation. Each key owns four samples and a running sum. Replacing one entry is constant time, and dividing by four becomes a right shift. With samples at ages zero, one, two, and three milliseconds, the moving average's mean age is approximately 1.5 milliseconds; that figure is derived from the window geometry, not a measured end-to-end latency. A longer filter would suppress more noise but add more delay and smear the threshold crossings used for velocity. Start your keyboard with raw logging, choose the smallest filter that makes idle noise comfortably smaller than the release threshold, and validate it with real key strikes.
