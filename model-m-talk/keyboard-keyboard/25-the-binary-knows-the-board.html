YOUR FIRST CONTRACT MCU + memory map + debug probe must agree.
コードも回路の一部 The repository is part of the circuit.
Start by making embedded Rust concrete. This crate does not build a desktop executable. The cargo target selects ARM Cortex-M with hardware floating point. memory.x tells the linker where the STM32H750's flash and RAM regions live. Embed.toml names the exact chip and enables RTT and GDB through the debug probe. main.rs opts out of the standard library and lets RTIC turn interrupts into scheduled tasks. The two commands are the shortest path on a machine where probe-rs is already installed: add the target once, then cargo run --release uses the runner declared in .cargo/config.toml. For your own keyboard, choose the MCU first and copy its proven target, memory, and probe configuration before writing scanning logic. Transition: once the binary can boot, give every stage exactly one responsibility.
