The Model M decision looked like a massive measurement and PCB task until mod-mmm provided a mechanical starting point. HE60 provided an open Hall-effect electrical reference. This is normal open-source engineering: understand both sources, then adapt them for a different geometry, controller, channel count, firmware, and musical purpose. Transition: this is not our first keyboard PCB, but the scale is new.
