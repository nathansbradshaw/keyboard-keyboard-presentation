Can a computer key measure motion—not merely a click?

Velocity is the inciting technical question. A conventional keyboard switch is binary. MIDI NoteOn carries a velocity value from 1 through 127. We need some observable property of key travel that can produce that value. Transition: ask people who work on keyboard sensing.
