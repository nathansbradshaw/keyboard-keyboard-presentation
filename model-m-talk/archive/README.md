# Archived presentation cuts

These are the presentation versions that predate the main keyboard-keyboard deck.

- `index.html` opens the discovery-led cut.
- `technical.html` opens the technical-first cut.
- `compare.html` displays both archived cuts side by side.
- `slides/` and `slides-discovery/` contain their preserved fragments.

The archive continues to use the shared assets, styles, loader, and Reveal configuration from the parent directory. Archived fragments can also be reused in the main deck by adding their `archive/...` path to `../slide-manifest.js`.
