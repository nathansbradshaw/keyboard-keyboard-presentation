MUSICAL GRID

A key participates in geometry.

switch index→(row, col)→MIDI note

Move right: +2 semitones. Preserve the shape: preserve the interval pattern.

意味が変わった。 An interface is the set of relationships it makes easy to learn.

Make the API metaphor concrete. A conventional keyboard reports key identity; the operating-system layout maps that identity to a symbol. Our firmware maps a physical switch index through a row-and-column musical geometry into a MIDI note. Horizontally, the Wicki-Hayden rows advance by whole tones, so moving right adds two semitones. The player learns relationships and shapes rather than isolated labels. The shell looks familiar, but the semantic contract with the hands is different. Transition: that was only one of several requirements that forced the architecture.
