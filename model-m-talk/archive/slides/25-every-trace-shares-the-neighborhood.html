Three GPIO bits address 104 sensor channels

pub fn set_mux_channel(ch: usize, s0: &mut Pin,
                       s1: &mut Pin, s2: &mut Pin) {
    if ch & 0b001 != 0 { s0.set_high() }
    else                { s0.set_low() }

    if ch & 0b010 != 0 { s1.set_high() }
    else                { s1.set_low() }

    if ch & 0b100 != 0 { s2.set_high() }
    else                { s2.set_low() }
}

Each address is broadcast first; the ADC fan-in is read second.

This code is faithful to hardware.rs; only the concrete Daisy pin types are shortened to Pin for readability. One three-bit channel address is broadcast to all thirteen key muxes, making 104 addressable slots. One hundred are mapped to physical switches. For each channel, firmware reads the nine direct ADC inputs and then selects the four decoded muxes. The trick saves GPIO and ADC pins, but means every signal shares address timing, settling time and ground quality. Transition: the board mistakes show where that shared architecture can fail.
